# AI Mathematics & Statistics Foundations

## 📌 Overview

This repository contains four team-based assignments completed as part of **Unit 2 of the AI & Data Science Bootcamp**.

The assignments focus on building a strong foundation in **Linear Algebra, NumPy, Matrix Operations, Eigenvalues & Eigenvectors, and Statistics**, emphasizing their applications in Artificial Intelligence (AI) and Machine Learning (ML).

Each assignment combines mathematical concepts, practical Python implementations, and theoretical explanations to connect mathematical foundations with real-world AI applications.

## 🎯 Learning Objectives

- Understand fundamental mathematical concepts used in AI and Machine Learning.
- Apply vector and matrix operations using NumPy.
- Explore eigenvalues, eigenvectors, and matrix transformations.
- Understand the mathematical foundations of Principal Component Analysis (PCA).
- Perform statistical analysis and visualization using Python.
- Interpret datasets and statistical findings to support Machine Learning decisions.

## 📂 Assignments

### Assignment 1 — Linear Algebra & NumPy Practice

**Topics Covered:**
- Scalars, vectors, matrices, and tensors
- NumPy array operations
- Array shapes and dimensions
- Mathematical operations and aggregations
- Vector addition and scalar multiplication
- Dot product, norms, and cosine similarity
- Linear independence and vector basis
- Linear combinations and transformations

**Objective:** Understand and implement fundamental linear algebra operations and explore their importance in Machine Learning.

### Assignment 2 — Matrix Algebra & Systems of Equations

**Topics Covered:**
- Matrix representation and dimensions
- Matrix arithmetic and transpose
- Matrix multiplication for AI predictions
- Matrix rank and redundant features
- Determinants and inverse matrices
- Identity matrices
- Solving linear systems using NumPy

**Objective:** Apply matrix algebra to practical scenarios and understand its role in AI prediction and feature representation.

### Assignment 3 — Eigenvalues & Eigenvectors

**Topics Covered:**
- Eigenvalue and eigenvector fundamentals
- Characteristic equations
- Manual and NumPy-based calculations
- Eigenvector normalization
- Geometric interpretation
- Matrix diagonalization
- Eigendecomposition
- Eigenvalues and Principal Component Analysis (PCA)

**Objective:** Understand how eigenvalues and eigenvectors describe linear transformations and contribute to dimensionality reduction in Machine Learning.

### Assignment 4 — Statistics for Machine Learning

**Dataset:** Titanic Dataset

**Topics Covered:**
- Exploratory Data Analysis (EDA)
- Variable classification
- Features and target variables
- Random and stratified sampling
- Descriptive statistics
- Data distributions and outliers
- Correlation and covariance analysis
- Statistical visualization
- Statistical insights and preprocessing considerations for ML

**Objective:** Analyze a real-world dataset using statistical methods and extract meaningful insights to support Machine Learning preparation.
